01

React · Operations · Workforce planning

Multi-Region Shift Planning Platform

Designed and built a dynamic React application that brings live shift activity from multiple regions into one operational view. Team members can record time away from operations for meetings, project work and breaks, giving engineers, leads and managers shared visibility as availability changes.

The platform supports shift setup, regional and shared coverage, call-outs, task rotations, time-off requests and approvals, readiness profiles, configurable certification and responsibility tags, audit reporting, user administration and role-based page access.

  • Live availability and regional coverage
  • Shift scheduling and task rotations
  • Readiness, certification and responsibility profiles
  • Time-off requests and approval workflows
  • Audits, reporting and role-based access
  • Multi-region coordination and handovers
ToolkitReact, live state management, serverless APIs and access controls
OutcomeClearer coverage, faster coordination and smoother cross-region handovers

Slack Operations & Status Automation

03

Cloud · Public APIs · Risk monitoring

Global Weather & Crisis Monitoring Platform

Designed a monitoring website that combines public weather and emergency-data APIs with a serverless backend to surface potentially disruptive events around critical facilities worldwide.

The platform collects and processes alerts, applies configurable geographic filtering, and presents relevant events through clear visualisations. Severe conditions can initiate targeted notification and ticketing workflows so responsible teams can assess possible risks to service continuity, power supply and site access.

  • Public weather and emergency-data ingestion
  • Serverless processing with AWS Lambda
  • Configurable geospatial monitoring
  • Global alert visualisation
  • Targeted notifications and ticketing workflows
ToolkitAWS Lambda, public APIs, geospatial filtering and dashboards
OutcomeEarlier visibility of severe events that could affect critical operations

05

Web application · API · Slack automation

Conference Bridge Operations Dashboard

Designed and developed an interactive dashboard that replaced an error-prone process of manually adding, updating and removing active conference bridge information through team messages.

An automation script detects new bridge activity and submits structured information through an API to keep the dashboard current. Users can assign ownership, update details, change status and close events, while a connected Slack bot publishes refreshed information whenever an event changes.

  • Automated event creation and API updates
  • Live ownership and status management
  • Slack bot notifications
  • Downloadable operational reports
  • S3-backed data retention
  • Administration, history and audit logs
ToolkitScripting, APIs, Slack automation, Amazon S3 and access controls
OutcomeReduced a manual update workflow from minutes to seconds

AI agents · Documentation

AI-Assisted Wiki Page Modernisation

Designed an AI-assisted workflow for modernising a knowledge base containing hundreds of wiki pages. The agent analyses each page’s source, content hierarchy, formatting and features before rebuilding it to a consistent standard.

The workflow preserves hyperlinks, images, files and attachments, and can transform plain-text drafts into complete wiki pages. This accelerates page creation and modernisation while reducing the risk of information or linked resources being lost.

CapabilitiesAgent design, source analysis, page generation and attachment mapping
OutcomeFaster, more consistent and maintainable wiki documentation
