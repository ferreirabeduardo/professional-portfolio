# Professional Portfolio

Personal portfolio website for Eduardo Ferreira, covering automation, AI integration, cloud systems, web development and data analysis.

## Pages

- `index.html` — introduction, services, selected work and background
- `portfolio.html` — project overview and case-study placeholders
- `assets/Eduardo_Ferreira_CV.pdf` — downloadable CV

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Before publishing

Review every project for NDA-safe wording, then add only approved screenshots, links and measurable outcomes.

## Deployment

The site is static and can be deployed directly to Cloudflare Pages. No build command is required; use the repository root as the output directory.
